 Ola Rides Analytics Dashboard | Power BI + SQL

An interactive data analytics dashboard built using Power BI and SQL to analyze ride booking trends, revenue performance, customer behavior, vehicle usage, and ride cancellation patterns for Ola ride services.

This project focuses on transforming raw ride-booking data into meaningful business insights through data cleaning, SQL querying, data modeling, and interactive visualizations.

# Key Insights & Features

* Ride volume analysis over time
* Booking status breakdown
* Revenue analysis by payment method
* Top customers by booking value
* Vehicle type performance by ride distance
* Customer vs Driver rating analysis
* Ride cancellation and incomplete ride reason analysis
* Interactive slicers for vehicle-based filtering

# Tools & Technologies Used

* SQL
* Power BI
* Data Visualization
* Data Cleaning
* DAX Measures
* Interactive Dashboard Design

# Dashboard Highlights

* Developed KPI cards for Total Rides, Revenue, Customer Rating, and Driver Rating
* Created multiple visualizations including line charts, bar charts, scatter plots, donut charts, and waterfall charts
* Applied a clean and aesthetic dashboard theme for better user experience
* Built an interactive and business-oriented reporting dashboard suitable for real-world analytics scenarios

# Project Goal

The goal of this project is to demonstrate how business intelligence tools can help ride-service companies monitor operational performance, customer satisfaction, and revenue trends through data-driven decision-making.
